WWM Personal Cabinet

Static mockups for student LK and admin CMS — analogous to AVO course editor: sections, lessons, rich text, video embeds, demo settings.

Student area

  • Sign in
  • My courses
  • Course — sections & lesson list
  • Lesson — formatted content + Kinescope
  • Lesson — locked (demo expired / paid only)

Admin CMS

  • Courses list
  • Students — lesson progress
  • Student detail — per-lesson opens
  • Course settings — sections, demo duration, demo lessons
  • Lesson editor — rich text + video insert
Scope: visual & UX reference only. No backend. Toolbar uses browser contenteditable for demo. The live app will persist lesson HTML in the database.
